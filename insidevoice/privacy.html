Inside Voice: Book Reader

Privacy policy

Effective August 20, 2026 Bassam Kamal bassamkamal.py@gmail.com

The short version

Inside Voice does not require an account. It does not sell data, run ads, or embed third-party analytics. Your books and reading progress stay on your device. Optional features (cloud AI keys, microphone transcription, neural voice download) only run after you turn them on, and only send what that feature needs.

This policy describes what Inside Voice does with data on your device, and what leaves the device when you choose to switch on an optional feature.

Data stored on your device

  • Books you import (EPUB or PDF), copied into the app's storage so moving the original file does not break the library.
  • Reading position, themes, voice choices, speed-reading settings, and similar preferences.
  • Rendered chapter audio and word timings, cached so a chapter does not have to be rebuilt every time you open it.
  • Optional API keys you enter for Gemini, Azure OpenAI, or Azure Speech, kept in the Keychain on your device.

The App Store privacy label for this build declares no tracking, and no collected data types sold or used for tracking. The app reads preferences, file timestamps, and system boot time only for ordinary on-device behaviour: settings, cache freshness, and timing.

Microphone

The microphone is used only if you start voice input in recall or chat. On a fresh install that path is off until you add an Azure Speech key and region in Settings and grant microphone permission. Audio for that feature is sent to Microsoft Azure Speech for short transcription, then discarded by the app once the text comes back. Typing always works without the microphone.

Optional network features

None of these are required to read a book aloud with system voices.

  • On device (default). Nothing leaves the phone. Available when Apple Intelligence is ready.
  • Gemini. Sends text you have already read, plus your recall or chat messages, to Google Gemini using an API key you paste. Only if you select Gemini.
  • Azure OpenAI. The same kinds of text, sent to your own Azure OpenAI resource. Only if you configure endpoint, deployment, and key.
  • Azure Speech. Sends short microphone recordings you start to Microsoft Speech, using your key and region. Only for voice input you trigger.
  • Neural voice install. Downloads model weights (via the neural voice package, from Hugging Face) only if you tap to install the optional voice.

Keys never leave the Keychain except as authorization headers on requests you start. The app does not operate a backend that stores your books or your chat history.

Children

Inside Voice is not directed at children under 13. Do not use the optional cloud features to send a child's personal information.

Third-party services

If you enable Gemini, Azure OpenAI, Azure Speech, or the neural voice download, those providers' own terms and privacy policies also apply to the data you send them. Inside Voice does not control how those providers retain logs on their side.

Changes

If this policy changes in a way that affects how the app handles data, the effective date at the top will update, and the App Store listing privacy URL will keep pointing here: https://bassamkamal.dev/insidevoice/privacy.html
