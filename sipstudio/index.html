iPhone companion for the QuadStick

Set up your QuadStick from your phone.

Called SipStudio inside the app. Listed on the App Store as Quadstick: Mobile Helper.

See what every sip, puff and switch does, change it, check it, and install it over USB-C. No spreadsheet required.

Coming soon to the App Store GitHub

Free to edit, check and install. No account.

01

See what every part does

Tap a tube, the lip switch or the joystick on a photo of the QuadStick and see what it does in the current mode. Pick which QuadStick model you own and the app shows that model.

02

Change it

Assign a controller button to a sip, puff, long sip, long puff or soft lip. Add, rename, reorder and delete modes. Undo any change.

03

Catch mistakes, then install

SipStudio checks the profile as you edit and lists any problem in plain words, with how to fix it, before it reaches the device. Then save the profile to the QuadStick over a USB-C cable using the Files app.

What is inside

Every profile, every mode, on your phone.

A QuadStick keeps its setup in profiles, one per game or activity, and each profile holds several modes. SipStudio lets you, or whoever helps you set it up, read and change all of it without a spreadsheet.
