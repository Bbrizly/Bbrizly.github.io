Bassam Kamal

Bassam Kamal is a Software Engineer at Iron Fox Games in Charlottetown, Prince Edward Island, where he ships production C++ and web tooling. He is a Computer Science graduate of the University of Prince Edward Island (2026), specializing in video games. Bassam builds production AI and machine-learning systems, custom 3D game engines, and accessibility technology, taking models from training through to on-device deployment, along with the C++ and CI/CD pipelines that ship them. His work includes Splat II, a multiplayer racing game on a custom C++ engine headed to Steam; QuadStick Config Manager, a free accessibility tool for quadriplegic gamers on the Mac App Store and Microsoft Store, covered by UPEI News; and Pluck, a Chrome and Firefox extension. His code is on GitHub at github.com/Bbrizly, and he can be reached at bassamkamal.py@gmail.com.
